# Hey, I'm Christian

I'm passionate about building with and for AI. Lately, I've been exploring agentic orchestration, multi-agent swarms, harness engineering, loop engineering, context engineering, and eval-driven feedback.

GitHub is where I try these ideas by building tools.

## What I'm working on right now

- **[Sloop](https://github.com/h-4vok/sloop)** — An issue-driven engineering harness that takes work through implementation, CI, and QA/SDET checks, with a human making the merge call.
- **[LLMChat CLI](https://github.com/h-4vok/llmchat-cli)** — A personal-alpha CLI and MCP project for talking to Gemini through a dedicated browser profile. Changes to the browser UI can break it.
- **[Diagram Tours](https://github.com/h-4vok/diagram-tours)** — I made Mermaid diagrams easier to explore by turning them into step-by-step browser walkthroughs.

My writing and ideas live on [my website](https://christianguzman.uk).
